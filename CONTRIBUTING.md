## Contributing

### First evening

You do not need to be good. Finish the small thing. English or German is fine.

Pick a [`good first issue`](https://github.com/shiftbloom-studio/circadian-ui/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22), comment on it, and open a focused pull request.

If you want a starting point, see [start here — pick a small door](https://github.com/shiftbloom-studio/circadian-ui/issues/41).

### Setup

```bash
npm ci
```

### Common scripts

- `npm test`
- `npm run lint`
- `npm run typecheck`
- `npm run build`

### Releasing

Add a changeset for user-facing changes:

```bash
npm run changeset
```
